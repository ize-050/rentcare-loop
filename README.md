# Rent Care Loop (concept prototype)

Clickable prototype of the Rent Care owner-care loop: owner request, BC finds a tenant, optional Vesta room work, handover into Smart World, repairs and approvals, monthly report, move-out, and back to a new tenant.

- Concept only. All names, prices and data are samples, not real systems or figures.
- Features shown are proposals and are not confirmed with the delivery teams.
- Open `index.html` in a browser. No build step.
